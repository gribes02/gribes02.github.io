# Portfolio - Guillem Ribes
> *Status: Active Development 🟢*

This repository contains the source code for my personal engineering portfolio website. The project serves as a central hub to showcase my work in **Robotics**, **Path Planning**, **Computer Vision**, and **Visual Language Action Models**.

## Project Overview

The website is designed with a **Cyberpunk/Sci-Fi** aesthetic. It is built using standard web technologies (**HTML5**, **Tailwind CSS**, **Vanilla JavaScript**) to ensure high performance.

## Key Modules

### 1. Main Hub (`index.html`)
The landing page containing:
*   **Hero Section**: Introduction and specialized tags (Robotics/AI).
*   **Journey**: A career journey visualization (BSc Mechanical Engineering, MSc Robotics).
*   **Skills**: A visual representation of technical competencies (ROS2, Python, C++, etc).
*   **Featured Projects**: Quick links to my key projects.

### 2. Interactive Terminal (`terminal.html`)
An easter egg feature simulating a retro Linux shell.
*   **Functionality**: Users can type commands like `help`, `cat about.txt`, `ls projects`, `cat cv.pdf` to explore the portfolio via text interface.
*   **Implementation**: A virtual file system implemented in JavaScript (JSON-based).

## Directory Structure

*   `assets/`: Static resources (css, js, images).
*   `CV.pdf`: My Curriculum Vitae.
*   `index.html`: Main portfolio page.
*   `terminal.html`: Interactive terminal page.
*   `contact.html`: Contact page.
